# FilmLightMeter 📸

Продвинутый экспонометр для Android, созданный специально для фотографов, снимающих на мануальные плёночные камеры. 

В отличие от стандартных приложений, которые усредняют сцену и программно пытаются вычислить яркость, **FilmLightMeter** использует аппаратный доступ к сенсору камеры через Camera2 API, получая чистые физические значения экспозиции и цифрового усиления (Sensor Boost).

## 🚀 Ключевые возможности

* **Настоящий Spot-замер (1° - 10°):** Аппаратный лок автоэкспозиции строго по центру кадра с возможностью оптического зума (до 4x) для точного замера конкретных объектов.
* **Push/Pull процессы:** Раздельный выбор профиля плёнки (задаёт кривую Шварцшильда) и рабочего ISO.
* **Эффект Шварцшильда (Закон невзаимозаместимости):** Автоматический пересчёт выдержек длиннее 1 секунды по логарифмической кривой для конкретной эмульсии (Tri-X, HP5+, Portra и др.).
* **Без лишнего нагрева:** UI на Jetpack Compose изолирован от потока камеры. Интерфейс не перерисовывается вхолостую, экономя заряд батареи на длительных съёмках.
* **Фиксация замера (HOLD):** Заморозка показаний для спокойного переноса параметров на механические кольца объектива.
* **Сохранение сетапа:** Выбранная плёнка, калибровка и зум автоматически сохраняются между сессиями.

## 🛠 Стек технологий

* **Kotlin** + **Android SDK** (Min SDK 26)
* **Jetpack Compose** (Material 3, State Hoisting, реактивный UI)
* **CameraX + Camera2Interop** (Прямой доступ к метаданным сенсора)
* **SharedPreferences** (Персистентность настроек)
